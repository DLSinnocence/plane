# 维护多语言文案

`src/locales/en/` 是文案键的基准。新增或调整文案时，应同步相关语言的同一命名空间文件；CI 要求所有语言具备英文源文件中的键，并检查源文案的命名空间冲突和路径冲突。

补齐前先拉取最新代码并核对英文源键的产品引用。已删除的按钮、说明或旧交互应先清理对应源键；动态拼接的状态、错误码及条件分支仍可能引用文案，不能只根据静态搜索未命中就删除。同步命令不会判断文案是否仍被产品使用。

```bash
# 复现 CI 完整性检查
pnpm --filter @plane/i18n check:sync

# 为缺失键补入英文源文案，保留所有现有译文
pnpm --filter @plane/i18n sync:fill

# 格式化并再次检查
pnpm --filter @plane/i18n fix:format
pnpm --filter @plane/i18n check:sync
```

`sync:fill` 只增加缺失项，不删除其它键、不覆盖已有字符串或清空的译文，也不改动英文源文件。尚未完成本地化的新增项先使用英文源文案，后续可逐项替换为对应语言的译文。ICU 占位符、复数表达式及换行会原样保留。

如果发现某个路径一边是字符串、另一边是对象，命令会报错，且不会写入任何语言文件；需要先人工解决结构冲突。同步后仍需运行 `check:sync`，不能以关闭检查或忽略缺失语言的方式通过 CI。
